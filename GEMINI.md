# Taste-Skill: Frontend Design System (tasteskill.dev)

This project follows the **Taste-Skill** design standards (https://www.tasteskill.dev).
All frontend generation, UI layout, typography, palette selection, and micro-interactions must adhere to:

1. **Anti-Slop Directives**: No purple-to-blue gradients, no nested cards, no generic 3-column feature grids, no cookie-cutter hero sections.
2. **Typography**: Intentional display + body pairing, strict heading scales (ratio ≥ 1.25), line width bounded to 65–75ch, no wrapped button/pill labels.
3. **Palette & Contrast**: Sophisticated tinted neutrals (warm or cool <5% sat), restrained accents, strictly WCAG AA compliant.
4. **Spacing & Radii**: Outer container padding ≥ inner gap, concentric radius formula (`Inner Radius = Outer Radius - Padding`), 2:1 button aspect ratio (`px = 2 * py`).
5. **Purposeful Motion**: Smooth springs/eases, tactile button states, no gratuitous bounces.
